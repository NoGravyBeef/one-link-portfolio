# 완주 체크리스트

- [ ] 최신 콘텐츠를 배포한 공개 주소가 다른 브라우저에서도 열린다.
- [x] 대상 문장과 공개·비공개 점검표가 있다.
- [x] 경험 1·2·3의 상황·행동·결과가 채워졌다.
- [x] 공개 가능한 근거 1개 이상이 연결됐다.
- [x] 두 해상도에서 핵심 3개가 보이고 가로 넘침이 없다.
- [x] 결함 3개 이상을 고친 전·후 기록과 콘솔 오류 0건 확인이 있다.
- [x] 상호작용이 마우스와 키보드에서 모두 작동한다.
- [x] 실제 콘텐츠를 반영한 페이지와 제출 기록에서 공개하지 않기로 한 개인정보가 0건이다.
- [x] 실제 콘텐츠를 반영한 페이지·배포 파일에서 비밀번호·토큰·API 키 등 비밀값이 0건이다.
- [x] AI 사용과 직접 판단을 3줄로 남겼다.

실제 콘텐츠 반영 후 개인정보·비밀값, 두 해상도, 상호작용 검사를 다시 실행했다. 최신 콘텐츠를 푸시한 뒤 공개 주소의 다른 브라우저 확인만 다시 수행한다.
