# 실제 결함 수정 기록

첫 구현과 자동 검사에서 실제로 발견한 문제를 기록했다.

## 결함 1 — 장식 배경이 섹션 너비를 넘김

- 수정 전: 1366×768에서 INTRO 영역이 109px, 1920×1080에서 154px만큼 내부 가로 넘침으로 측정됐다.
- 수정 내용: 화면 밖에 음수 좌표로 배치했던 배경 빛을 섹션 내부에 두고 이동 범위를 줄였다.
- 수정 후: 두 해상도에서 문서와 모든 주요 영역의 가로 넘침이 0건이다.

## 결함 2 — 빌드 설정 경고

- 수정 전: Vite 8 빌드에서 `__dirname` 사용이 향후 기본 설정과 호환되지 않는다는 경고가 발생했다.
- 수정 내용: 다중 페이지 입력 경로를 `import.meta.dirname` 기준으로 변경했다.
- 수정 후: 프로덕션 빌드가 경고와 오류 없이 완료된다.

## 결함 3 — 배포 작업의 패키지 관리자 불일치

- 수정 전: 저장소는 pnpm 잠금 파일을 생성했지만 배포 작업은 `npm ci`를 실행하도록 작성돼 배포 실패 가능성이 있었다.
- 수정 내용: GitHub Actions에서 pnpm을 설치하고 `pnpm install --frozen-lockfile`과 `pnpm run build`를 사용하도록 통일했다.
- 수정 후: 로컬과 배포 작업이 같은 잠금 파일과 명령을 사용한다.

## 결함 4 — 상호작용 화면 기록의 위치 오류

- 수정 전: 경험 선택 검사는 통과했지만 화면 기록이 INTRO 섹션을 촬영해 상호작용 결과를 증명하지 못했다.
- 수정 내용: 상호작용 완료 후 경험 섹션을 정확히 화면 시작점에 맞추고 위치를 검사한 다음 촬영하도록 변경했다.
- 수정 후: 경험 버튼의 선택 상태와 바뀐 상세 본문이 같은 화면 파일에 기록된다.
